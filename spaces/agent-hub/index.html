02Staged for publish

Seven Docker services are in the repo. py -3 deploy.py publishes the chat and this page. py -3 deploy.py --docker adds the rest, and that step needs Hugging Face PRO.

02n8nPRO
Workflows and agent nodes. The webhook is set on deploy. The first visit creates the owner.
port 7860 · N8N_ENCRYPTION_KEY
03Local ChatPRO
Open WebUI and Ollama. Models are baked at build. The first signup is the admin.
port 8080 · llama3.2:1b · qwen2.5:0.5b
04OpenMusePRO
Personal agent: browser, terminal, and files. The public URL is baked into the image for anubhavg-icpl.
port 7860 · replace the two SET_ME secrets
05FlowisePRO
Visual agent builder. Sign in as fleet-admin. The password is generated on deploy.
port 7860 · FLOWISE_USERNAME / FLOWISE_PASSWORD
06LangflowPRO
Visual flows with a run endpoint. The superuser name is langflow.
port 7860 · LANGFLOW_SUPERUSER_PASSWORD
07AnythingLLMPRO
RAG workspace. Finish the wizard before sharing the URL. No secret is injected.
port 3001 · /app/worker/storage
08LobeChatPRO
Chat UI gated by an access code. Provider keys stay in the browser.
port 3210 · ACCESS_CODE
GitHub Pages hosts the HTML. The hub and the chat are at anubhavg-icpl.github.io/agent-fleet. The same files run from a local server. Docker Spaces use a token in state\hf_token and py -3 deploy.py --docker. That step needs Hugging Face PRO.
